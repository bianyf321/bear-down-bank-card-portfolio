# bear-down-bank-card-portfolio
Tableau dashboard for card portfolio analysis

## Project Overview
This project presents an interactive Tableau dashboard analyzing Bear Down Bank's card portfolio, customer generations, and income distribution.

## Published Tableau Dashboard
[View the interactive dashboard on Tableau Public](https://public.tableau.com/app/profile/yufan.bian/viz/1_17924734549550/1?publish=yes)

## Key Finding and Recommendation
- Early replacement cohort: 477 non-contactless cards are scheduled to expire in 4–6 months.
- Estimated replacement cost: $3,816, calculated at $8 per card.
- Recommendation: Evaluate this cohort for an early replacement campaign and prioritize eligible customers based on the bank's budget and operational needs.

## Dashboard Views
1. Non-Contactless Cards by Expiration Window
2. Customer Portfolio by Generation
3. Customer Income Distribution
